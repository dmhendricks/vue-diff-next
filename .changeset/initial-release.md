Initial release.

A drop-in replacement for the retired [`vue-diff`](https://github.com/hoiheart/vue-diff):
same props, same defaults, same split and unified rendering, verified against the
original's own output. Ships 35 bundled languages in 16.3 kB gzip.

`virtualScroll` is accepted and sets the viewer height, but does not yet window the
output — see "Not yet implemented" in the README.
