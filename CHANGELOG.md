# vue-diff-next

## 1.0.0-rc.0

### Major Changes

- [`3de5c95`](https://github.com/dmhendricks/vue-diff-next/commit/3de5c955d5af6a6863eea7214d57ba3249a5b038) Thanks [@dmhendricks](https://github.com/dmhendricks)! - Initial release.

  A drop-in replacement for the retired [`vue-diff`](https://github.com/hoiheart/vue-diff):
  same props, same defaults, same split and unified rendering, verified against the
  original's own output. Ships 35 bundled languages in 18.4 kB gzip.

  Includes virtual-scroll windowing for large diffs, folding (`dots` / `hunk` markers),
  a soft-wrap toggle, and the `custom*` theme escape hatch.
